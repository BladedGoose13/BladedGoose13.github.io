# BladedGoose13.github.io

Upload everything in this folder to the root of the `BladedGoose13.github.io` repository.
GitHub Pages serves `index.html` at https://bladedgoose13.github.io/.

- `index.html`: the home page with the desk.
- `cv.pdf`: web copy of the CV, without the phone number.
- `og.png`: link preview for LinkedIn and chats.
- `img/`: photos for the Experience sliders (WebP, loaded lazily).
- `.nojekyll`: tells GitHub Pages to serve the files as they are.
